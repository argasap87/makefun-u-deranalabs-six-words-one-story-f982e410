One complete story in exactly six words:

> He planted trees he'd never shade.

## Run

```sh
node main.ts
```

This writes the story to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` if set). The program throws unless the text is exactly six words and 1–60 characters.
